## Manual Testing Steps

### Step 1: Start Backend Services
`ash
cd S:\BackEndSureLM
docker-compose up -d       # Start PostgreSQL, Qdrant, Ollama
npm run dev                # Start Next.js backend on port 3000
`

### Step 2: Test Backend directly (curl)
`ash
curl -X POST http://localhost:3000/api/chat 
  -H "Content-Type: application/json" 
  -d '{"messages":[{"role":"user","content":"Health insurance for farmers"}],"stream":false}'
`

### Step 3: Configure Android App
1. Open S:\BackEndSureLM\SureLMFrontEnd in Android Studio
2. Edit local.properties: 
   `
   API_BASE_URL=http://YOUR_IP:3000
   CLERK_JWT_SECRET=your-secret
   `

### Step 4: Build and Run App
`ash
cd S:\BackEndSureLM\SureLMFrontEnd
.\gradlew.bat assembleDebug
`
